What this answers: what is planned, in what order, and why.

Part of the [project wiki](../index.md). One canonical home per fact -

## What is planned next, in what order, and why that order?

Proposal, not commitment - the owner decides.

- A `check --base` pre-push hook recipe in the docs (CI already enforces it).
- Publish a release tag per version from the changelog section.
- Windows-native hook runner, so the hooks need no `sh`.
- A loudness eval: a fixed set of prompts and a line-count assertion on real replies.
- More platforms only if asked (non-goal today).
